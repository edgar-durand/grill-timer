# Grill Timer

Temporizadores de parrilla con aviso de giro, alarma suave y notificación al terminar.

Made with [CodeAgent Remix](https://www.codeagent-mobile.com/remix). Live app: https://grill-timer-sm6mlx4r.remixapps.app/

## Run it locally

A React Native app for [Expo](https://expo.dev) (SDK 54), in TypeScript. You need Node.js 20 or newer.

```bash
npm install
npx expo start   # scan the QR code with Expo Go
```
